# IsoGuide — Simple Multi-Page Guide Website

This project is a multi-page website built using only **HTML5**, created as part of a web development assignment.  
The goal is to practice building structured pages, internal navigation, semantic elements, and basic form creation.

---

## 📁 Project Structure

The project contains **4 separate HTML files**, all linked through a navigation menu:

- index.html → Home Page
- about.html → About Page
- services.html → Services Page
- contact.html → Contact Page


Each file includes:
- A valid HTML5 document structure
- `<head>` section with `<title>` and `<meta charset="UTF-8">`
- A shared navigation menu at the top
- Appropriate headings, text, lists, and semantic elements

---

## 🏠 Home Page (index.html)

Includes:

- Main heading (`<h1>`)
- Introduction text using paragraphs
- Image with proper `alt` text  
  _Example: A person writing on a whiteboard during a workshop_
- A bullet list describing key offerings

---

## 👤 About Page (about.html)

Includes:

- Section heading (`<h2>`)
- Two descriptive paragraphs
- A milestone timeline using an ordered list (`<ol>`)

---

## 🛠 Services Page (services.html)

Includes:

- Multiple service sections, each with:
  - `<h2>` sub-heading
  - `<p>` descriptive text
- A bullet list of service types

---

## ✉️ Contact Page (contact.html)

Includes:

- Heading + short paragraph
- Contact details listed inside `<ul>`
  - Address
  - Phone
  - Email
- A working HTML form with:
  - Name input
  - Email input
  - Message textarea
  - Submit button

_No backend is required — this is a static example form._

## 🚀 How to Run

1. Download all `.html` files into the same folder  
2. Open `index.html` in any browser  
3. Use the navigation menu to visit the other pages
