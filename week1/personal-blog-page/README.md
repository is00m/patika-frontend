# Iso's Personal Tech Blog

This is an HTML project created as part of an assignment to build a simple personal blog page using pure HTML and CSS.

---

## 📌 Project Summary

This blog showcases:
- Personal journey and reflections on learning web development
- Three posts about starting HTML, choosing fullstack development, and balancing coding with real life
- Use of responsive design elements, list structures, semantic HTML tags, and embedded images


---

## 🛠️ Technologies Used

- **HTML5** for structural layout
- **CSS (Internal Styles)** for styling
- **Links and Images** referenced via external sources

---

## 🧩 Features

- Semantic HTML elements such as `<header>`, `<section>`, `<h1>`, `<h2>`, `<p>`, `<ul>`, `<ol>`, `<img>`, and `<a>`
- Three distinct blog posts with images, lists, and external resources
- Clean and modern design using CSS with:
  - `box-shadow`
  - `border-radius`
  - `hover` effects
  - Responsive image sizing

---

## 🔗 External Resources Used

- Images sourced from [Pexels](https://www.pexels.com)
- Educational content linked to:
  - [MDN Web Docs – HTML Guide](https://developer.mozilla.org/en-US/docs/Learn/HTML)
  - [Dev.to Articles](https://dev.to)

## 🚀 How to Run

1. Download or clone the project folder.
2. Open the `blog.html` file in any modern web browser (Chrome, Firefox, Edge, etc.).
3. Explore the blog structure and content.
