# CV Web Page Project

This is a simple CV webpage built using **HTML**, **CSS**, and embedded **Google Maps**. The aim is to create a clean, responsive resume that contains personal information, education, professional experience, skills, and location details.

---

## 🧑‍💻 Features

- **Header** with name, title, and contact icons (Email, LinkedIn, GitHub)
- **Summary** section for brief introduction
- **Education** section listing academic history
- **Professional Experience** showcasing relevant roles and achievements
- **Skills list** highlighting technical abilities
- Embedded **Google Maps iframe** displaying location visually

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Inline & Internal)
- Google Maps Embed API

---

## 💻 How to Run

Simply open the `web-page.html` file in any modern web browser to view the resume.

---

## 📌 Notes

- Icons are sourced from external URLs (Flaticon and GitHub Assets).
- The design uses a subtle background pattern for texture.
- All links (email, LinkedIn, GitHub) open in new tabs.
- The project is responsive enough for basic desktop use.
