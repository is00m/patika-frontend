# Notes App

A simple React + Vite notes app. Add notes with a selected color, filter them with the search input.

## Features
- Add notes from a textarea
- Pick a color for each note before saving
- Filter notes by text

## Getting Started
```bash
npm install
npm run dev
```

## Project Structure
- `src/App.jsx` — UI and state logic
- `src/App.css` — component styles
- `src/index.css` — global theme
