# Instagram Clone (Static)

A simple, static Instagram-style layout built with Bootstrap 4 and Font Awesome. Stories and posts use placeholder images and dummy user names (customer1…8) for demonstration.

## Features
- Fixed navbar with search box, nav icons, and profile avatar.
- Horizontal stories strip with avatars and labels.
- Feed cards with images, action icons, likes, and comments.
- Sticky right column showing profile and suggestions.

## Getting Started
1) Clone/download this repo.  
2) Open `index.html` in your browser (no build steps needed).

## Tech
- HTML, CSS, Bootstrap 4.5
- Font Awesome 6 (CDN)

## Notes
- All images are from Unsplash placeholders; replace with your own assets as needed.
