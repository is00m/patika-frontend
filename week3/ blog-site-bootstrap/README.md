# Blog Site (Bootstrap)

Simple two-page blog layout built with Bootstrap 5. Includes a hero, featured cards on `index.html`, and a sample multi-card list on `post.html`.

## Run Locally
- Open `index.html` in your browser (or use a live server extension).
- Navigation links jump between the home and post pages; images come from `picsum.photos`.

## Tech Stack
- HTML5, Bootstrap 5 CDN, Font Awesome CDN
- Small custom tweaks in `styles.css`

## Project Structure
- `index.html` — hero section + featured posts
- `post.html` — simple list of blog posts
- `styles.css` — optional custom styles
