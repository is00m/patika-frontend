# LinkedIn Clone

A modern and responsive LinkedIn clone application. Built using Bootstrap 5 and Font Awesome icons, designed with a dark theme for a professional look.

## 🎨 Features

- **Responsive Design**: Compatible with mobile, tablet, and desktop devices
- **Dark Theme**: Professional and modern appearance
- **Interactive Components**: Hover effects and animations
- **Post Cards**: Aesthetic design with shadows and rounded corners
- **Navigation Bar**: Navbar with search and quick access links
- **Profile Card**: Card displaying user information and statistics

## 🛠️ Technologies

- **HTML5** - Page structure
- **CSS3** - Styles
- **Bootstrap 5** - Responsive grid system and components
- **Font Awesome 6.5.2** - Icons

## 🚀 Usage

1. Open the `index.html` file in a web browser
2. Use the navbar links to navigate the page
3. View and interact with the posts

## 📝 Content

### Header
- LinkedIn logo
- Search bar
- Navigation menu (Home, My Network, Jobs, Messaging, Profile)

### Main Content
- **Left Panel**: User profile card and statistics
- **Center Panel**: Social media posts (Patika.dev and Kodluyoruz)
- **Right Panel**: LinkedIn News and featured jobs


## 🎯 Design Features

- **Colors**: 
  - Background: #000000 (Black)
  - Text: #dce6f1 (Light Gray)
  - Accent: #0a66c2 (LinkedIn Blue)

## 🖼️ Customizing Images

To change post images:
1. Update the `src` URL in the `.post-image img` tag in the `index.html` file
2. Or use your own image URL

Currently using service: [Lorem Picsum](https://picsum.photos/)
