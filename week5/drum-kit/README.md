# Drum Kit

A simple interactive drum kit built with basic HTML, CSS, and JavaScript.

## Features

- Clickable drum buttons with matching sounds
- Keyboard support for quick playing (A, S, D, F, G, H, J, K, L)
- Visual pressed state for active buttons

## Project Structure

```
week5/drum-kit/
├── assets/
│   ├── boom.wav
│   ├── clap.wav
│   ├── drum.png
│   ├── hihat.wav
│   ├── kick.wav
│   ├── openhat.wav
│   ├── ride.wav
│   ├── snare.wav
│   ├── tink.wav
│   └── tom.wav
├── index.html
├── script.js
└── style.css
```

## How to Run

Open `index.html` in your browser and start playing.

## Controls

- A: Kick
- S: Snare
- D: Hi-Hat
- F: Clap
- G: Open Hat
- H: Boom
- J: Ride
- K: Tink
- L: Tom
