# Patika Week 6 - To-Do Studio

A dark-themed to-do list with local storage, filters, and a progress meter.
Built as a simple, stylish single-page app for practice.

## Features

- Add, complete, and delete tasks
- Filter by All / Active / Done
- Progress bar with completion percentage
- Local storage persistence
- Responsive layout and subtle motion

## Usage

Open `index.html` in your browser. Tasks are saved automatically in local
storage.

## Project Structure

- `index.html` - Markup and layout
- `css/style.css` - Styles and animations
- `js/app.js` - App logic and storage
