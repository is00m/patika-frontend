# Dice Game (React + Vite)

A minimal dice duel game where Player 1 (user) rolls against Player 2 (PC). Each round rolls once, animates the dice for a short time, and then shows win/lose/draw results on screen. The UI is intentionally clean and dark, inspired by modern game platforms.

## Features
- Single-round dice duel (Player 1 vs PC)
- 3-second rolling animation before the final result
- Dynamic status message and button label
- Customizable Player 1 name

## Getting Started

Install dependencies:
```bash
npm install
```

Run the dev server:
```bash
npm run dev
```
